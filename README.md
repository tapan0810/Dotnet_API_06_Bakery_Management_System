# Bakery Management API

ASP.NET Core Web API practice project for managing bakery-related records through RESTful endpoints.

## Focus
- ASP.NET Core Web API
- Entity Framework Core
- CRUD operations
- Dependency Injection
- SQL Server / relational data access

## Running
```bash
dotnet restore
dotnet run
```

Configure the database connection in application settings before using database-backed endpoints.
